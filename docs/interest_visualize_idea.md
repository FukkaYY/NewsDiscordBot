# 今の関心度を見る機能

## 概要

- ユーザーが現在の自分の関心度（ジャンル別の重み付き平均スコア）を確認できる機能を提供します。

## 機能詳細

- **スラッシュコマンド**: `/interest`
- **表示内容**:
  - 全ジャンルのリストと、それぞれの現在のスコア（5点満点）。
  - スコアは降順（高い順）で表示。
  - 視覚的なバー（例: `[■■■□□]`）を表示して直感的に理解しやすくする。

## 技術仕様

- **データ取得**:
  - `bot.get_genre_scores()` メソッドを呼び出して取得する。
  - このメソッドは `news_ratings` と `news_genres` テーブルから重み付き平均を算出する。
- **デフォルト値**:
  - 評価データがないジャンルはデフォルト値 `3.0` として表示する。
- **計算ロジック**:
  - 重み = `1 / (経過日数 + 1)`
  - スコア = `Σ(評価 × 重み) / Σ(重み)`
  - （評価が0件の場合は `3.0`）

## 表示イメージ

- 政治: `[■■□□□]` **2.50**
