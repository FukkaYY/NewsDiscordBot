# 概要

ニュースを決まった時間に自動送信するアプリ。
Discord botとして実装する。

## 基本機能

- 一日2回(日本時間の9:00, 17:00)にその日のニュースを5件ピックアップして、discordの指定チャンネルに自動送信する。
- ニュースのジャンルは一旦ランダムで。
- 前回送ったニュースとの重複が無いようにする。

## 実行環境(サーバー)

- AWSのEC2上で常駐。[参考サイト](https://qiita.com/Minmin067/items/68f787f7b4afa2986588)

## データベース

- SQLite

## Discord

### 受信メッセージ

- 選定されたニュースのタイトルと本文リンクをペアにする。
- 埋め込み式

### 送信コマンド

- /setup
  - サーバー管理権限所持者のみ実行可能。
  - ニュース受信チャンネルを、このコマンドを実行したチャンネルにする。

## Gemini

- ジャンルについては一旦丸投げ。
- gemini apiを使用する。
- 使用モデルは精度重視。
- 正しいリンクが答えられているか確認してほしい。

## シークレット情報の管理

- 基本的には.envファイルで管理する。
