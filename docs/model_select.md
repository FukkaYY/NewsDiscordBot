# AIモデル切り替え機能

## 概要

Botが使用するGeminiのモデル（例: `gemini-1.5-flash`, `gemini-1.5-pro`）を、プログラムの再起動なしにコマンドから切り替える機能。

## 目的

- ニュースの要約精度を上げたい場合に、一時的に上位モデル（Proなど）に切り替える。
- レート制限やコストを考慮して、通常時は軽量モデル（Flashなど）を使用する。

## 仕様

### 1. モデルの保存方法

- データベース（SQLite）の `config` テーブル、または新しい `system_settings` テーブルに現在のモデル名を保存する。
- 起動時は、環境変数の `GEMINI_MODEL_NAME` をデフォルトとしつつ、DBに設定があればそれを優先する。

### 2. 管理者コマンド

管理権限を持つユーザーのみが実行可能とする。

- `/model status`
  - 現在使用中のモデル名を表示する。
- `/model set [model_name]`
  - 使用するモデルを切り替える。
  - 選択肢（AutoComplete）を表示し、誤入力を防ぐ。
- `/model list`
  - 利用可能な主要モデルの一覧を表示する。

### 3. 対応モデル（初期候補）

### 3. 対応モデルの管理

- `models.md`（または `models.txt`）という外部ファイルで管理する。
- ファイルには1行に1つモデル名を記述する。
- ボットは起動時やコマンド実行時にこのファイルを読み込み、`/model set` の選択肢（AutoComplete）を動的に生成する。
- これにより、新モデル（例：`gemini-2.0-flash-exp`）への対応がコード修正なしで可能になる。

## 内部処理の変更

1. `NewsBot` クラスの初期化時に、`models.md` を読み込み利用可能なモデルリストをメモリに保持する。
2. `NewsBot` クラスの初期化時に、DBから最新のモデル設定を読み込む。
3. モデル切り替えコマンドが実行された際、`self.model` インスタンスを新しいモデル名で再生成する。
4. エラーハンドリング: `models.md` に存在しないモデルが指定された場合や、APIエラーが発生した場合は、デフォルトの Flash モデルにフォールバックする。
