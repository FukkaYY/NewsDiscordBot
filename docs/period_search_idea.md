# 特定の期間で検索をかける機能

## 機能案

- 期間を指定し、その期間のニュースから関心度の高いジャンルのものを3件ピックアップする機能。
- 期間の最初と終わりの年月日を指定して検索をかけ、AIに選定させる。
- 検索はWeb全体から
- 年月日の入力は文字列で自由入力
- /period_searchとして実装

## 実装詳細

### 1. コマンド仕様

- コマンド名: `/period_search`
- 引数:
  - `start_date` (文字列): 開始日 (例: 2024-05-01)
  - `end_date` (文字列): 終了日 (例: 2024-05-07)

### 2. 処理フロー

1. **日付解析**: 入力された文字列を `datetime` 形式に変換。不正な形式の場合はエラーメッセージを返す。
2. **関心度取得**: `get_genre_scores()` を呼び出し、ユーザーの関心度が高い上位3ジャンルを特定する。
3. **ウェブ検索**:
    - 上位ジャンルをキーワードに含め、DuckDuckGoで検索を実行。
    - 検索エンジンの制約内（timelimit等）で可能な限り期間を絞り込む。
4. **AIによる選定 (Gemini)**:
    - 検索結果のリスト、指定された期間、および利用可能な全ジャンルをGeminiに渡す。
    - 「指定期間内のニュースであること」「高関心ジャンルを優先すること」を条件に、最も重要な3件を選定・要約させる。
5. **結果表示**:
    - 選定された3件を個別のEmbedとして送信。
    - 各ニュースには評価用の `RatingView` を付与し、その後の関心度計算にフィードバックする。

### 3. 注意事項

- DuckDuckGoの検索APIの仕様上、厳密な「○月○日から○月○日まで」というフィルタリングが難しい場合があるため、Geminiによる抽出段階で期間の整合性を最終チェックする。
