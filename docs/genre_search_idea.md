# ジャンル指定してニュース検索する機能

## 概要

- 指定したジャンルに関連するニュースを、過去の配信履歴（DB）と最新のインターネット検索の両方から探し出す機能を提供します。

## 機能詳細

- **スラッシュコマンド**: `/genre_search [ジャンル]`
- **引数**:
  - `genre`: 検索したいジャンル名（オートコンプリート対応予定）。
- **検索内容**:
    1. **履歴検索**: `news_history` および `news_genres` テーブルから、指定ジャンルに合致する過去の配信済みニュースを最大3件取得。
    2. **最新検索**: DuckDuckGoを使用して現在のニュースを検索し、Geminiで指定ジャンルへの適合性を判定。上位最大3件を取得。

## 技術仕様

- **履歴検索ロジック**:
  - `SELECT ... FROM news_history JOIN news_genres ... WHERE genre = ? ORDER BY sent_at DESC LIMIT 3`
- **最新検索ロジック**:
  - DDGSで「[ジャンル名] 最新ニュース」等のキーワードで検索。
  - 取得したURLとタイトルをGeminiに渡し、指定ジャンルに合致するか判定・要約させる。
- **UI/UX**:
  - 検索に時間がかかるため `interaction.response.defer()` を使用。
  - 結果はEmbedで「過去のニュース」「最新のニュース」のセクションに分けて表示。
