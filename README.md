# News Discord Bot

Gemini APIを使用して、最新のニュースを自動的にDiscordチャンネルに配信するBotです。

## 機能

- **定期配信**: 毎日 9:00 と 17:00 (JST) にニュースを5件配信します。
- **パーソナライズ**: ユーザーの評価（関心度）に基づき、Gemini (gemini-1.5-flash) が最適なニュースを厳選・要約します。
- **重複排除**: 過去に配信したニュースとの重複を自動的に避けます。
- **検索機能**: `/genre_search` で特定のジャンルのニュースを履歴と最新Web検索の両方から探せます。
- **関心度の可視化**: `/interest` コマンドで、自分の今の関心度をグラフ形式で確認できます。

## セットアップ

1. 必要なライブラリのインストール:

    ```bash
    pip install -r requirements.txt
    ```

2. `.env` ファイルの作成:

    `.env.example` をコピーして `.env` を作成し、各トークンを設定してください。
    - `DISCORD_BOT_TOKEN`: Discord Developer Portalから取得
    - `GEMINI_API_KEY`: Google AI Studioから取得

3. Botの実行:

    ```bash
    python main.py
    ```

## 使用方法

1. **初期設定**: ニュースを配信したいチャンネルで `/setup` コマンドを実行します（管理者権限が必要）。
2. **関心度の評価**:
   - 届いたニュースの下部にある 1〜5 のボタンを押して評価してください。
   - 評価は何度でも修正可能です。
   - 評価データは時間とともに減衰（新しい評価を重視）し、次回の配信内容に反映されます。
3. **コマンド**:
   - `/interest`: 現在のジャンル別関心度を5段階のバーで表示します。
   - `/genre_search [ジャンル]`: 指定したジャンルの過去ニュースと最新ニュースを表示します。最新ニュースはその場で評価可能です。
   - `/test_news`: 即座に配信テストを実行します（管理者のみ）。
   - `/setup`: 配信チャンネルを設定します（管理者のみ）。
   - `/logs [lines] [download]`: Botの動作ログを確認またはダウンロードします（管理者のみ）。
